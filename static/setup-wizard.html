Set up this server

Five things to decide, then it restarts once and is yours. The rest of the server waits here until they are answered.

1
The address people reach this server on

Every link this server sends is built from it, every paired Kobo stores it, and a passkey is bound to it. It is not how the server listens — that is set in the environment file and shown on the admin page.

A name, not an address and not a URL. Leave it empty on a laptop and the server calls itself by its listen address.

Mail

Without it there is no confirmation link, no password reset and no emailed sign-in. The server still works — the messages go to its log instead, which is enough for one person and wrong for anybody else.

5
Converters

As it stands this server takes an EPUB and sends it to a Kobo as a KEPUB, repairing the layout on the way. That covers Kobo, Tolino and PocketBook and needs nothing further. Everything else — Kindle formats, PDF, and reading a KFX — is fetched onto this machine when you ask for it, because it is most of a gigabyte and most servers never use all of it.

Whatever you tick is fetched in the background, in that order, while you carry on. Nothing here waits for it, and the progress is on the Converters page.

6
One restart and it is done

Waiting on a restart

This server is not running in a container, so nothing would start it again if it exited. Everything is saved. Restart the process yourself and the address above takes effect; the rest is already live.
