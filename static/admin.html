Putting one back

There is no button for this, on purpose: restoring over a running server would race whatever it is doing. Stop it first, then unpack.

docker compose down && tar -xzf send2ereader-backup.tar.gz -C /your/data && docker compose up -d

The archive holds db/ and library/, which is the shape of the data directory. Unpacking it over that directory puts both back where they were. If the session key was lost with the server, sessions end and stored Kobo tokens and two-factor secrets cannot be read — everything else returns.

Restart the server

Some settings only take hold on a restart — the ones marked on their field. Everything else is already live and needs none of this.
